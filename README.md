# MFB Portal

Web app for Midwest League Fantasy Baseball: every team's roster, 2027 keeper round values, MLB stats and a keeper planner.

- **Page:** `index.html` (hosted on GitHub Pages).
- **Data:** loaded from the league's Google Apps Script (`?format=json`), which reads the back-end Google Sheet and refreshes MLB stats daily from the MLB Stats API.

No league data is stored in this repository.
